# generated_paths.txt: the deny list of stillhere's packaged policy
# (docs/spec/classification.md#deny-list).
#
# Format. Every line that is not blank and does not start with # is one RE2
# pattern (Go regexp syntax: no lookaround, no backreferences), matched with
# MatchString against the full repo-relative path, with forward slashes.
# Surrounding whitespace is ignored, and a # later in a line is part of the
# pattern, not a comment. A path that any pattern matches is denied: it adds
# nothing and is never blamed, unless .gitattributes unsets
# linguist-generated or linguist-vendored for it.
#
# Source. The first two sections are translated from GitHub Linguist,
# https://github.com/github-linguist/linguist, at commit
# 73ee9a3b277f398c37ca4ab0dea0193849de6460 (main on 2026-10-14), the commit
# the curator read:
#   - lib/linguist/vendor.yml. Its patterns are valid RE2 already (Linguist's
#     script/check-regex-compatibility checks each one against Go's engine,
#     and its allowlist of exceptions is empty), so they are copied
#     unchanged, with their comments. Six are left out on purpose; they
#     stay in place as comments, and the last section gives the reason.
#   - lib/linguist/generated.rb: the rules that read only the path. Ruby
#     regexp literals lose their delimiters, /i becomes (?i) and \/ becomes
#     /. go_vendor? uses lookaround, which RE2 lacks, and is rewritten
#     without it. Rules that read file content cannot be path patterns and
#     are left out; the header sniff (classification.md#header-sniff) covers
#     those whose header holds one of its markers.
# The third section is stillhere's own: the minimum contents of
# classification.md that Linguist lacks. Editing any line changes the policy
# hash of every run that uses the packaged policy.

########################################################################
# Left out on purpose
########################################################################
#
# Six vendor.yml rules stay commented out in section 1. The first two
# match a directory name that commonly holds a team's own code. Linguist only drops
# such files from a repository's language bar; stillhere would silently drop
# their authors' lines from every ownership, durability and knowledge
# number. A repository that does keep third-party code there can say so with
# linguist-vendored in .gitattributes, and a policy file can add the pattern
# back to its deny list.
#
# (^|/)cache/  "Caches". A Go internal/cache or a Python app/cache package
#              is first-party code, and build caches are rarely committed.
#              Laravel's generated bootstrap/cache is denied in section 3.
# (^|/)env/    "django". An env/ package or env/ configuration is
#              first-party code. Virtual environments are denied as venv
#              and .venv in section 3.
#
# The other four match continuous integration's configuration and a
# team's deployment tasks, which are its own infrastructure: the packaged
# policy gives them the iac role, as it does a Makefile or a Dockerfile, so
# who wrote and who knows the release, test and deployment automation can
# be answered (policy revision 3, 2026-10-16). Linguist drops these files
# from a language bar only.
#
# (^|/)\.github/     "GitHub.com". Workflows and actions are iac, and so is
#                    code under .github/, which only CI runs; issue,
#                    discussion and pull request templates and FUNDING.yml
#                    are doc ([[roles.path]] in default.toml). The bundles an
#                    action commits (dist/, node_modules/) stay denied by
#                    their own rules.
# (^|/)Jenkinsfile$  "Jenkins Pipeline": iac by its name.
# (^|/)\.teamcity/   "teamcity CI configuration": its Kotlin DSL (.kts) and
#                    XML are iac by their extensions, and code there by a
#                    path rule, as under .github/.
# (^|/)fabfile\.py$  "Fabric": a project's Fabric tasks, which deploy and
#                    release it, as a Makefile's targets do; iac by a
#                    [[roles.path]] rule in default.toml.
#
# Two segments of stillhere's own are left out of section 3 for the same
# reason; Linguist has neither. In a census of the 175,079 files with a
# role in 1,120 Go modules (a module cache, 2026-10-14), the files under
# either segment were the modules' own packages, scripts and test data,
# never vendored code or build output:
#
# (^|/)build(/|$)    221 files, such as Go's go/build package and Thrift's
#                    build/docker scripts. Build output is in every common
#                    .gitignore template; a repository that commits it can
#                    mark it linguist-generated.
# (^|/)storage(/|$)  1,083 files, such as go-git's storage/ and Kubernetes'
#                    storage/v1 API types. The rule was for Laravel, whose
#                    storage/framework and storage/logs section 3 denies.
